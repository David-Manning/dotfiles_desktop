# Conventions

## Writing
- British English spelling and vocabulary. Dates as YYYY-MM-DD.
- Plain, neutral tone. No slang, no emojis, no em dashes.
- Use "written", not "drafted", unless it means an early version.
- No praise, no restating my request, no closing summaries, no offers or questions at the end.
- If a request is genuinely ambiguous, ask a short question first; otherwise proceed.

## Code
- Follow the patterns, style and libraries already used in the repository.
- Keep changes to what the request needs: no unrelated refactoring or reformatting.
  Mention other problems you notice, but do not act on them unasked.

## Git
- Do not commit unless I ask. Leave changes uncommitted for me to review.
- When I ask you to commit, use Conventional Commits prefixes (feat:, fix:, docs:, and so on),
  with a message that says what changed and why.
- Never commit credentials or tokens.
- Ask before anything destructive or hard to undo: deleting files, rewriting history, force-pushing.
